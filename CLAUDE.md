# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

JUniverse: "the whole universe coded in Java" — a domain model of physical reality, from atoms up to galaxies, with real physical constants and formulas. Java 17 target, Maven, Lombok, JUnit 5.

## Commands

```sh
mvn test                                        # build + run all tests
mvn test -Dtest=AtomTest                        # one test class
mvn test -Dtest=AtomTest#carbon_isotopes        # one test method
mvn compile && java -cp target/classes com.enlil.universe.Main   # run the demo (no exec plugin configured)
java -cp target/classes com.enlil.universe.simulation.FranceHistory   # simulate the history of France since Clovis
```

There is no Maven wrapper and no linter/formatter configured.

## Architecture

Base package `com.enlil.universe`, split into five layers:

- **`celestial`** — generic astronomy types. `CelestialObject` (just a name) is implemented by `Galaxy` and by the abstract `CelestialBody` (mass + radius, validates both positive, computes `surfaceGravity()`). `Star`, `Planet`, `NaturalSatellite` extend `CelestialBody`. Containment is a strict tree: `Galaxy → Star → Planet → NaturalSatellite`, each holding an immutable `List.copyOf(...)` of its children; aggregates like `Galaxy.getPlanets()` / `Universe.getStars()` flatten via streams. Physics lives on the types (e.g. `Star.orbitalPeriodDays(planet)` via Kepler's third law, `SpectralClass.fromTemperature`). Each `Planet` and `NaturalSatellite` has an `Orbit` (fixed J2000 Keplerian elements including inclination and node, no precession; the `double semiMajorAxisAu` planet constructor makes a circular one). Periods use Kepler's third law with both masses (`Orbit.periodDays(totalMassKg)`). `Star.positionOf(planet, instant)` / `Planet.positionOf(moon, instant)` solve Kepler's equation for a 3D ecliptic `OrbitalPosition`; `Star.closestApproach` scans day by day and `Star.illuminatedFraction` gives a moon's phase. Only the Earth's Moon has a real orientation and phase; other moons have real size and shape only. Time is an `Instant` measured from `PhysicalConstants.J2000`. Constants in `PhysicalConstants` (SI units).
- **`world`** — concrete real-world instances as no-arg/parameterless subclasses with hardcoded real values: `Earth` (comes with its `Moon`; `new Earth(creatures)` populates it, `new Earth()` is lifeless), the other seven planets (each with its major moons as inline `NaturalSatellite`s), `Sun` and nearby stars (`AlphaCentauriA`, `ProximaCentauri`, `Sirius`), `MilkyWay` and the Local Group galaxies (`Andromeda`, `Triangulum`, `LargeMagellanicCloud`, whose stars are not modeled). Bodies use their mean radius, so gas giants' surface gravity differs from NASA's equatorial figures. Parents take their children as constructor args (`new Sun(List.of(earth))`), so the tree is assembled bottom-up — see `Main`.
- **`matter`** — atomic physics, independent of `celestial`. `Atom` = `Nucleus` (protons/neutrons) + electron count; it is immutable (`ionize()` / `gainElectron()` return new atoms) and charge/ion/isotope logic derives from the counts. `ChemicalElement` enum covers only the first elements of the periodic table — `Atom`'s constructor rejects atomic numbers not in it. `ElectronConfiguration` fills `Subshell`s in Madelung order (aufbau; known exceptions like Cr/Cu deliberately not modeled). Constants in `AtomicConstants`. Each `ChemicalElement` carries its melting/boiling points at 1 atm (helium's melting point is `NaN`, carbon sublimates), from which `StateOfMatter.of(element, temperatureKelvin)` gives solid/liquid/gas (plasma is never derived). `ClassicalElement` (earth, water, air, fire) maps Aristotle's hot/cold, dry/wet qualities onto a `StateOfMatter`.
- **`life`** — living things. `Creature` (species, `Kingdom`, `massKg`) knows its weight under a given gravity; `Planet` holds an immutable list of creatures alongside its moons, and `planet.weightNewtons(creature)` uses the planet's surface gravity. `life.human.Human` is a `Creature` (Homo sapiens, ANIMALIA) built with `Human.builder()` from a `Body` (sex, age, height, mass; adults only) and a `BloodGenotype` (ABO and RhD allele pairs, Mendelian `offspring` Punnett square), with an optional mother and father linked child-to-parent only (validated by sex, age and inheritable genotype; `getAncestors`, `isSiblingOf`, Wright's `relationshipCoefficient`); it derives its `Blood` volume (Nadler) and takes sex-specific ICRP 89 reference `Organs` masses (not scaled to the individual). `Body` computes BMI/WHO category, BMR (Mifflin–St Jeor), surface area (Mosteller), max heart rate (Tanaka) and vital capacity (ERS 1993); `Blood` handles red-cell transfusion compatibility. A required `Mind` holds a Big Five `Personality` (percentile scores 0–100), an IQ (percentile via the normal CDF, WAIS-IV `IqClassification`) and a set of hobbies, each an `Activity`. In `life.human.activity`, the abstract `Activity` (name, metabolic equivalent ≥ 1 MET) gives its WHO `Intensity` (sedentary/light/moderate/vigorous at 1.5/3/6 MET) and `kcalBurned(body, hours)` = MET × mass × hours (also `human.kcalBurned(activity, hours)`); its forms are `Sport` (players per side), `MusicalPractice` (an instrument in its Hornbostel–Sachs `InstrumentFamily`) and `Pastime` (any other `ActivityCategory`: arts, games, outdoors...). Real activities are constants in `world.activity.Activities`, with Compendium of Physical Activities (2011) MET values. A human may know `LanguageSkill`s (builder `languages`, each language once; a mother tongue, or hours studied mapped to CEFR `Proficiency` by Cambridge guided learning hours, PRE_A1 to C2, then NATIVE) and can `speak(language, words)` (a `Speech` at 150 words per minute; `IllegalStateException` below A1), `learn(language, hours)` (returns a new `Human`, the old one unchanged) and `sleep(hours)` (a `Sleep` of 90-minute `SleepCycle`s whose `SleepStage` minutes follow a textbook model: N3 fading, REM lengthening, leftovers as N2; one `Dream` per REM period, only the last remembered; NSF 2015 recommended hours by age and sleep debt). Real languages are constants in `world.language.Languages` (Ethnologue native speakers). `Sex` is the sex assigned at birth. A `Body` may also carry an `IntersexVariation` (Klinefelter, Turner, complete androgen insensitivity, congenital adrenal hyperplasia, with their `Karyotype` and frequency; the assigned sex is not checked against it) and a gender-affirming `HormoneTherapy` (feminizing/masculinizing, years); `getHormonalSex()` is the therapy's sex once established (≥ 1 year), else the assigned sex. Hormone-driven quantities (BMR, Nadler blood volume, the WHO anemia threshold `Blood.isAnemic`) use the hormonal sex; skeleton-bound ones (vital capacity, ICRP organs) keep the assigned sex. Being intersex counts toward `isLgbtq()`; a human may disclose an `Identity` (builder `identity`, `getIdentity()` empty when not disclosed, nothing assumed) in `life.human.identity`: a `GenderIdentity` (woman, man, non-binary, genderfluid, agender), a self-identified `SexualOrientation` (not checked against gender) and `Pronouns` (subject/object/possessive, neopronouns allowed); cisgender/gender-diverse/LGBTQ+ are derived against the sex assigned at birth; transgender too for binary genders, while non-binary people may say whether they call themselves trans (counted trans when they don't say) (`isTransgender()`, `isLgbtq()`, false when undisclosed). `Polity` has overridable `getSameSexMarriageYear()` (empty by default) and `criminalizesHomosexuality()` (false by default), set on the real nations. A required `Physiognomy` holds eye/hair color, hair texture and a Fitzpatrick `SkinType` whose minimal erythema dose gives `minutesToSunburn(uvIndex)`.
- **`civilization`** — the abstract `Civilization` (name, population, `powerWatts`; validates population and power positive) derives Sagan's Kardashev rating `(log10 P − 6) / 10`, its `KardashevType` (0/I/II/III at 10^16/10^26/10^36 W), power per capita and `yearsToReach(type, annualGrowthRate)`. Subclasses implement `getSpecies()` and `getEra()` (a chronological `TechnologicalEra`). A `Planet` holds its civilizations alongside its creatures (`new Earth(creatures, civilizations)`), and `Galaxy` / `Universe.getCivilizations()` flatten them; a civilization does not point back to its planet. A civilization holds the `Polity`s it was organized into over its history (`politiesIn(year)`) and the `Discovery`s it knows, sorted by year (`getSciences()`, `discoveriesIn(science)`, `knownBy(year)`). `civilization.science` has the `Science` disciplines, each in a `ScienceBranch` (formal, natural, social, applied); real discoveries are constants in `world.science.Discoveries`, starting with the ones this codebase implements (Kepler, Newton, Bohr, Mendeleev, Mendel, Landsteiner, Binet, the Big Five, Lemaître). In `civilization.polity`, the abstract `Polity` (name, capital, population, `areaSquareKm`, `TerritorialOrganization`, founded and optional dissolved year, then a required `Currency`; historical years, negative for BCE, no year 0, so `durationYears` / `ageYears` skip it) leaves `getHeadOfStateTitle()` and `getSuccession()` to its forms: the abstract `Monarchy` (`MonarchyType` absolute/constitutional) with the hereditary `Kingdom`, `Empire`, `Principality` and `Sultanate`; `Republic` (elected, a `SystemOfGovernment` and a head-of-state term); `Theocracy` (a religion and its leader). Real polities live in `world.polity` as no-arg subclasses with 2024 figures: republics `France`, `UnitedStates`, `Germany`, `China`, `Switzerland`; kingdoms `UnitedKingdom`, `SaudiArabia`; the empire `Japan`; `Monaco` (principality), `Oman` (sultanate), `VaticanCity` (theocracy); `Malaysia` extends `Monarchy` directly as an elective monarchy; and the historical `RomanEmpire` (27 BCE–476). `civilization.economy` has `Currency` (optional ISO 4217 code, symbol, `MonetaryStandard` commodity/representative/fiat, minor units per unit: 100 cents, 1,000 baisa, 16 asses, 1 for the yen) and the immutable `Money`, counted exactly in a `long` of minor units, refusing to mix currencies (compared by identity), with compound inflation (`purchasingPowerAfter`, `yearsToDoublePrices`). Real currencies are shared constants in `world.economy.Currencies` (the euro serves France, Germany, Monaco and Vatican City). A civilization's money system derives from its polities: `getCurrencies()`, `getMonetaryStandards()` (empty means barter). A civilization also holds its `Occupation`s, past and present (`occupationsIn(year)`). In `civilization.occupation`, the abstract `Occupation` (name, ISCO-08 `OccupationGroup`, the `Science`s it relies on, since/optional until year) leaves `isArmed()` to `CivilOccupation` and `ArmedOccupation` (a `Force`: military, law enforcement, intelligence; at least one `Weapon`), and `Warrior` is an armed military class with a code of honour, hereditary or not. Real ones live in `world.occupation`: `Doctor`, `Engineer`, `Teacher`, `Firefighter`, `Soldier`, `PoliceOfficer`, `FbiSpecialAgent`, `SecretAgent`, the Roman `Legionary`, and the warriors `Knight` and `Samurai`. Its constructors take, in order, name, population, power, then optional lists of polities, discoveries and occupations. Real ones live in `world`: `Humanity` (present day, holding a dozen modeled states) and `AncientRome` (2nd-century peak, Ian Morris's energy capture, holding the `RomanEmpire`).

- **`simulation`** — runnable programs, each with its own `main`. `FranceHistory` walks the years from Clovis (481) to today over `world.history.HistoryOfFrance`: its fourteen regimes as `Polity` constants (generic `Kingdom` / `Empire` / `Republic` instances, plus `FrenchState`, Vichy's appointed regime, extending `Polity` directly; the Provisional Government of 1944–1946 is a deliberate gap), dated `civilization.history.HistoricalEvent`s, French `Discoveries`, occupations (with the `Musketeer`), and a `currencies()` timeline (solidus, livre of 240 deniers, franc germinal, fiat franc, euro) finer than regimes, since a `Polity` holds only its last currency.

At the root: `Universe` (Lombok `@Builder` with `@Singular galaxies`) and `PrimitiveAtom` (Lemaître's primeval atom, not a chemical atom — its `bigBand()` builds an empty universe). `BigBangFlow<T>` is a small "creates something" interface implemented by `Universe`.

## Conventions

- Units are encoded in names (`massKg`, `radiusMeters`, `semiMajorAxisAu`, `surfaceTemperatureKelvin`, `orbitalPeriodDays`); keep doing so, and document units in Javadoc for derived quantities.
- Domain objects are immutable: `final` fields, defensive `List.copyOf`, Lombok `@Getter` rather than `@Data` (only `Universe` uses `@Data`). Invalid physical input throws `IllegalArgumentException` in the constructor.
- Never use `Optional` / `OptionalInt` as a field type. Store an absent value as a nullable field (`Integer`, `String`) excluded from Lombok with `@Getter(AccessLevel.NONE)`, documented as null when absent, and expose it through a hand-written getter returning `Optional` / `OptionalInt`.
- Numeric literals use underscores for readability (`6.674_30e-11`).
- Tests use JUnit 5 `Assertions` (AssertJ is on the classpath but unused), one test class per type mirroring the main package, snake_case method names plus a `@DisplayName` sentence, and tolerance-based `assertEquals` checks against real-world values.
- Commit messages are imperative sentences describing the modeling step (e.g. "Model atoms with their nucleus, electrons and elements").
